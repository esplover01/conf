# Conference Booking System

Веб-приложение для бронирования конференц-залов и переговорных комнат. Проект реализован на Node.js с использованием Express, EJS и SQLite. Пользователи могут регистрироваться, входить в систему, создавать заявки на помещение и отслеживать их статус, а администратор — подтверждать или отклонять запросы.

## Описание проекта

Приложение представляет собой маленькую систему управления бронированием помещений для конференций и встреч. Основные сценарии:

- регистрация нового пользователя;
- авторизация и хранение сессии;
- просмотр списка доступных комнат;
- создание заявки на использование комнаты;
- просмотр личной панели пользователя;
- управление заявками в административной части;
- отметка статуса заявки и комментарий/отзыв.

## Основные возможности

### Для обычных пользователей

- Регистрация по логину, паролю, ФИО, телефону и email;
- Вход в систему;
- Просмотр комнат по категориям: конференц-зал, переговорная, open space;
- Создание заявки с указанием даты и способа оплаты;
- Просмотр истории своих заявок;
- Просмотр деталей заявки и возможность оставить отзыв после завершения.

### Для администратора

- Вход под логином `Conf2027`;
- Просмотр всех заявок пользователей;
- Изменение статуса заявки (`Новая`, `В работе`, `Завершено` и т.д. в зависимости от логики интерфейса);
- Просмотр деталей заявки, ��ключая информацию о пользователе и комнате.

## Технологический стек

- Node.js

## Схема данных

В приложении используется SQLite и несколько таблиц:

- `users` — пользователи системы
- `rooms` — комнаты и их описание
- `requests` — заявки на бронирование
- `reviews` — отзывы по завершённым заявкам

Реализация моделей и инициализация базы данных находятся в файле `db.js`.

1. Установите зависимости:



3. Откройте в браузере:

## Основные маршруты

- `/rooms` — список комнат
- `/register` — регистрация
- `/login` — вход
- `/dashboard` — личная панель пользователя
- `/create` — создание заявки
- `/admin` — панель администратора
- `/request/:id` — детали заявки
- `/logout` — выход из системы

## Важные замечания

- Сессия пользователя поддерживается через `express-session`.
- Для маршрутов, доступных только авторизованным пользователям, используется проверка `requireAuth`.
- Для административных разделов используется `requireAdmin`.
- В проекте предусмотрен контроль неактивности пользователя: если сессия простаивает более 20 минут, происходит перенаправление на страницу входа.
